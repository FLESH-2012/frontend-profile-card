# 🌟 Frontend Profile Card

Zamonaviy va responsive profil kartasi loyihasi. Ushbu loyiha HTML, CSS va JavaScript yordamida yaratilgan bo‘lib, frontend dasturlashni o‘rganayotgan dasturchilar uchun amaliy mashq sifatida xizmat qiladi.

---

# 📖 Loyiha haqida

Frontend Profile Card — bu foydalanuvchi haqida ma'lumotlarni chiroyli va zamonaviy ko‘rinishda taqdim etuvchi web komponent hisoblanadi.

Kartada quyidagi ma'lumotlar mavjud:

- Profil rasmi
- Ism va familiya
- Kasbi yoki mutaxassisligi
- Qisqacha bio
- Ijtimoiy tarmoqlar havolalari
- Tugma (Button)
- Hover animatsiyalar
- Responsive dizayn

Ushbu loyiha frontend dasturlash asoslarini o‘rganayotganlar uchun juda foydali hisoblanadi.
